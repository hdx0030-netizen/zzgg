# 喵格研究所

[打开猫咪人格测试](https://hdx0030-netizen.github.io/zzgg/) · [下载完整Vue源码](https://hdx0030-netizen.github.io/zzgg/source.html)

30道交错排列的原创问题，同时探索日常与恋爱倾向，生成一张融合猫格牌。包含8只原创SVG猫咪、八维柱状图、自动保存进度和高清PNG导出。

根目录index.html是独立生产构建，可由GitHub Pages从main分支根目录直接发布。source.html提供完整模块化Vue 3 + TypeScript + Vite工程ZIP下载。

解压源码后运行：

```sh
npm install --registry=https://registry.npmjs.org
npm test
npm run dev
```
